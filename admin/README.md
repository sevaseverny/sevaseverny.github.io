# Админка портфолио (локальная)

Первый раз задать пароль (хеш попадёт в `admin.config.json`, в git его нет):

    python3 tools/admin_server.py --set-password

Запуск:

    python3 tools/admin_server.py

Открыть http://127.0.0.1:8800/admin/ (сервер слушает только этот компьютер).

Что делает «Сохранить»: пишет `data/portfolio.json` (копия предыдущей версии в `data/backups/`) и запускает
`tools/build_gallery.py`, который пересобирает галерею и контакты в `index.html`. Дальше как обычно: проверить, закоммитить, запушить.

Загрузка: JPG пересжимаются с качеством 77 (с учётом EXIF-поворота), PNG/GIF/WebP кладутся как есть. Имена файлов очищаются.
Удаление из блока не удаляет файл из `images/`.
